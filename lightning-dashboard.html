⚡ WeatherSTEM "closest lightning" — beta, best-effort. WeatherSTEM's widget API only reports a yes/no "lightning detected within range" signal for the coordinates you give it (not a precise distance/bearing/time), and it's designed to render on one whitelisted domain rather than be queried directly. Yes, hosting matters: WeatherSTEM keys are restricted to a list of hostnames/IPs you approve when you create the key, checked in-browser against the page's own address — a file opened straight off your computer (a file:// address) has no hostname at all, so it will not pass, no matter how correct the key is. Host this file somewhere with a real address (even a plain http://<your-ip> or a static site) and add that exact host to the key's allowed list, or this panel will just sit empty. Once it's hosted right, this panel auto-moves the widget to whichever venue you select and re-checks it every few minutes — no need to click anything after that. Your key is only kept in this browser's local storage — it's never written into the file itself.
